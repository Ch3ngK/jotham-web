# jotham-web

Portfolio website for Jotham Tay, freelance photographer & videographer.

Static HTML/CSS/JS site — no build step needed. Open `index.html` directly in a
browser, or serve the folder with any static server (e.g. `npx serve .`).

## Adding real content

Placeholder tiles show until real files are added.

**Photos** — drop images into these folders using the existing numbering, and
add matching entries to the `PHOTO_GALLERIES` / `HERO_IMAGES` arrays at the top
of `script.js`:

- `assets/hero/`
- `assets/photography/music/`
- `assets/photography/nightlife/`
- `assets/photography/events/`
- `assets/photography/portraits/`

**Videos** — edit the `VIDEOS` array in `script.js` and fill in each `id` with
the YouTube video ID (the part after `v=` in the video URL).
